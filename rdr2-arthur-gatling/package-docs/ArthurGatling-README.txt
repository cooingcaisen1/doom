Arthur's Gatling - Red Dead Redemption 2, Story Mode only

F7 ........ bring the Gatling out / put it away
Fire ...... hold to spin up and spray (no reloading)
No sprinting while it's out. Rides, wagons, swimming or death put it away.

If an online session starts, the mod goes idle. Use it in Story Mode only.
Log: ArthurGatling.log in the game folder.
Needs Ultimate ASI Loader (Melty installs it).
